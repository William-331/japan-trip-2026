# Japan Trip 2026

7 位朋友的 2026 年日本九日旅行规划网页。

## 在线访问

GitHub Pages 启用后访问：

<https://william-331.github.io/japan-trip-2026/>

## 行程范围

2026 年 8 月 18 日至 8 月 26 日：

> 大阪 → 奈良 → 京都 → 河口湖 → 东京

## 网页内容

- D1—D9 每日行程与时间安排
- 城市导览与景区图鉴
- 手绘交互路线地图
- 交通方式、预计耗时和预算
- 餐饮与当地美食建议
- 标准、高温和雨天预案
- 可在浏览器中保存勾选状态的准备清单
- 手机端、桌面端与打印布局

## 本地查看

可以直接打开 `index.html`，也可以在项目目录启动静态服务器：

```bash
python -m http.server 4173
```

然后访问：

<http://localhost:4173/>

## 内容说明

行程、票价、开放时间、交通班次和天气信息可能变化，出发前及当天应通过官方网站复核。当前摄影素材未接入网页，页面使用项目内自制的 CSS 插画和文字占位。
