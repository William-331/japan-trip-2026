# Japan Trip 2026

5 位朋友的 2026 年日本十日旅行规划网页。

## 在线访问

GitHub Pages 启用后访问：

<https://william-331.github.io/japan-trip-2026/>

## 行程范围

2026 年 8 月 18 日至 8 月 27 日：

> KIX → 大阪 → 奈良 → 京都 → 河口湖 → 东京 → HND

核心安排包括大阪城、USJ、奈良日游、京都清晨精简线、河口湖一晚与三个完整东京日。8 月 27 日 06:00 从羽田飞香港。

## 网页内容

- D1—D10 每日行程与时间安排
- 城市导览与景区图鉴
- 手绘交互路线地图
- 交通方式、预计耗时和预算
- 餐饮与当地美食建议
- 标准、高温和雨天预案
- 奈良人工寄存及羽田夜间等待的待复核提示
- 可在浏览器中保存勾选状态的准备清单
- 手机端、桌面端与打印布局

## 本地查看

可以直接打开 `index.html`，也可以在项目目录启动静态服务器：

```bash
python -m http.server 4173
```

然后访问：

<http://localhost:4173/>

行程、票价、开放时间、交通班次、行李规则、机场夜间开放和天气信息可能变化，出发前及当天应通过官方网站复核。近铁奈良站 5 号口附近人工寄存点的信息来自用户提供的现场经验，不代表官方保证。当前页面使用项目内自制的 CSS 插画和文字占位。
